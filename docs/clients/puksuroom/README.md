## Evidence of an existing billiards community

CueScore records **Viikkokisat 13.9**, an **8-ball** event at Puksu Room on **13 September 2026**, with **seven participants** and a **double-elimination** format. These are event-specific historical facts, not an estimate of normal attendance. The fetched event page is preferred over search snippets, which can show an earlier participant count. [S3]

**Project interpretation, not a venue commitment:** a future camera/tracking pilot could support an existing billiards activity rather than require a new tournament community. Existing tournament administration should be treated as something to complement, not replace. No CueScore integration has been implemented or agreed.

## Physical context: leads, not a survey

The Venuu listing describes screens, darts, Wi-Fi and separate event spaces. Its main description mentions one pool table, while another section mentions two. Seating/capacity descriptions also vary within the listing. **Current table count, table dimensions, room layout, equipment availability and usable camera-mounting positions are not verified.** [S4]

Photos are visual references only; they are not measured plans or proof of the current layout. See [MEDIA.md](MEDIA.md) for source links and reuse status, and [SITE_SURVEY.md](SITE_SURVEY.md) for a blank inspection template.

A public source can still be inappropriate to aggregate or republish when it is irrelevant to the engineering case study.
